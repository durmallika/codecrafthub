# CodeCraftHub

## Project Overview and Features

CodeCraftHub is a simple, personalized learning platform designed for developers to track their courses. Built with Java and the Spring Boot framework, this RESTful API allows users to manage their learning path effortlessly.

### Features:
- **CRUD Operations**: Add, retrieve, update, and delete courses.
- **Data Storage**: Store course data in a simple JSON file (`courses.json`).
- **Course Tracking**: Each course includes details like name, description, target completion date, status, and creation timestamp.
- **Validation**: Proper error handling for missing required fields and invalid input values.
